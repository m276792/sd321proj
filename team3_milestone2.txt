=============================================================
FUNCTIONAL DEPENDENCY SUMMARY
=============================================================
- Country: country_id → country_name, iso_code
- EconomicIndicator: (country_id, year) → all economic measures
- EconomicImpactEvent: event_id → all event attributes
- Emission: (country_id, year) → all emission measures

=============================================================
BCNF EVALUATION
=============================================================
All relations are in BCNF:
 - Every non-trivial functional dependency has a superkey on the left-hand side.
 - No partial or transitive dependencies exist.

=============================================================
ER MODEL DESCRIPTION
=============================================================

Entities:
-----------
• **Country**
  - PK: country_id
  - Attributes: country_name, iso_code

• **EconomicIndicator**
  - PK: (country_id, year)
  - FK: country_id → Country
  - Attributes: economic measures (GDP, inflation, unemployment, etc.)

• **EconomicImpactEvent**
  - PK: event_id
  - FK: country_id → Country
  - Attributes: date, event_type, severity, damages, aid, casualties

• **Emission**
  - PK: (country_id, year)
  - FK: country_id → Country
  - Attributes: total, coal, oil, gas, cement, flaring, other, per_capita emissions

Relationships:
---------------
1. Country —< EconomicIndicator  (1:N)
2. Country —< Emission           (1:N)
3. Country —< EconomicImpactEvent (1:N)

=============================================================
NOTES
=============================================================
- Using **country_id** (or ISO code) as the linking key ensures dataset integration.
- The “EconomicIndicator” and “Emission” tables are **time-series** per country-year.
- “EconomicImpactEvent” captures discrete events, typically multiple per year per country.
- Each dataset maps naturally:
   - work_bank_data → EconomicIndicator
   - emissions → Emission
   - economic_impact → EconomicImpactEvent
- All are normalized to BCNF to prevent redundancy and update anomalies.
